SHT31（温湿度センサー）メイン

SHT31 の中温度と湿度を測り、センサーの中で 0〜65535 の数字に変換デジタル 16ビット
I2C（線4本）ラズパイが「測って」と命令し、数字を受け取る電源・信号とも 3.3V
ラズパイ数字を ℃・% に計算し、壊れていないか確認（CRC）5秒ごと
記録補正を足して、1分ごとにSDカードへ。警報の判定もここ1分ごと

つなぎ方

  • センサー：Adafruit SHT31-D（基板の上に SHT31 が載ったもの）
  • ラズパイのピン → ブレッドボード → SHT31-D の4本（線の色は今の配線）
    • 緑：1番ピン（3.3V）→ ブレッドボードの ＋ の列 → SHT31-D の VIN
    • 茶：6番ピン（GND）→ ブレッドボードの － の列 → SHT31-D の GND
    • 紫：3番ピン（GPIO2 = SDA、データ）→ SHT31-D の SDA
    • 青：5番ピン（GPIO3 = SCL、時計の合図）→ SHT31-D の SCL
  • 電源：ラズパイの 3.3V（SHT31-D は 2.5〜5.5V で動く）
  • ADDR ピンを VIN につないで、I2C の番号（アドレス）を 0x45 にしている

数字の計算（データシートの式）

温度[℃] = -45 + 175 × 温度の数字 ÷ 65535 湿度[%] = 100 × 湿度の数字 ÷ 65535
  • 例：温度の数字が 26214 なら -45 + 175 × 26214 ÷ 65535 = 25.0℃
  • 測るたびに「高精度・1回測定」の命令を送る。読み間違いは CRC（検査用の数字）で見つけて捨てる
  • 管理欄の「補正」の数を足してから記録・判定する（例：-0.5 なら 0.5℃ 下げる）
  • SDカードの記録は、その1分の区切りで測った値（平均ではない）

Pt100（白金測温抵抗体）比較用

Pt100白金の線。温度で抵抗が変わる0℃で100Ω、1℃で約0.385Ω増える
Y2Kb Pt100 モジュール小さい一定の電流を流して電圧を測り、抵抗 → 温度に変換温度の文字にして送る
USBUSBシリアル（CH341）で文字を送る10秒ごと・921600bps
ラズパイ「現在,平均,最大,最小」の行から現在の温度を取り出し、補正を足して記録1分ごと

つなぎ方

  • Pt100 の線 → Y2Kb の Pt100 温度測定モジュール → USB ケーブル → ラズパイ
  • モジュールの電源は USB から（5V）
  • 差し込み口：ラズパイの hcd.0 側（最初から差していた方）。K型熱電対と逆に差すと名前が入れ替わる
  • USB ケーブルはデータ通信できるものが必要（充電専用だとランプは点くが認識されない）

数字の考え方

抵抗[Ω] ≒ 100 × (1 + 0.00385 × 温度[℃]) （JIS / IEC の Pt100） 例：25℃ → 約109.6Ω、0℃ → 100Ω
  • 温度への変換はモジュールの中で行い、ラズパイは送られてきた温度の文字をそのまま使う
  • -50〜200℃ を外れた値は、断線などの疑いとして記録しない

K型熱電対比較用

K型熱電対2種類の金属（クロメル・アルメル）の先端の温度差で電圧が出る1℃の差で約0.041mV
Y2Kb K型熱電対モジュールごく小さい電圧を測り、つなぎ目側の温度（冷接点）を足して温度に変換温度の文字にして送る
USBPt100 と同じ形で文字を送る10秒ごと・921600bps
ラズパイPt100 と同じプログラムを「ktc」の名前で動かして記録1分ごと

つなぎ方

  • K型熱電対 → Y2Kb の K型熱電対モジュール → USB ケーブル → ラズパイ
  • モジュールの電源は USB から（5V）
  • 差し込み口：ラズパイの hcd.1 側（あとから差した方）

数字の考え方

出る電圧 ≒ 0.041mV × (先端の温度 − つなぎ目の温度) 例：先端 25℃・つなぎ目 20℃ → 約0.2mV。モジュールがつなぎ目の温度を測って足し、先端の温度を出す
  • 電圧がとても小さいので、線を長くしたり、ノイズの多い電線の近くを通したりすると値がふらつきやすい
  • -200〜1300℃ を外れた値は、断線などの疑いとして記録しない
  • 指で先端をつまむとすぐ温度が上がる（どちらのモジュールか確かめるときに使える）

THD-R-C（4〜20mA 温湿度センサー）比較用

THD-R-C温度・湿度を電流で出す（2本）4〜20mA
150Ω の抵抗電流を電圧に変える0.6〜3.0V
RPi-GP40T電圧を 0〜4095 の数字に変える（1目盛り 1.25mV）SPI でラズパイへ
ラズパイ電圧 → 電流 → ℃・% に計算し、補正を足して記録5秒ごと（記録は1分ごと）

つなぎ方

  • 温度：THD-R-C の A → GP40T の A0。A0 と G0 のあいだに 150Ω
  • 湿度：THD-R-C の B → GP40T の A1。A1 と G1 のあいだに 150Ω
  • G0・G1 は THD-R-C の電源の −（GND）へ
  • THD-R-C の電源：DC 24V。ACアダプター（BS-ACDC シリーズ 24V、PSE マーク付き、プラグ 外径5.5mm・内径2.1mm、極性はセンタープラス＝プラグの中心が＋）→ パワーコネクター（2芯の電源用コネクター。プラグを＋と－の線に分ける）→ THD-R-C の電源の＋・－
  • 4〜20mA の電流は、24V の電源 → THD-R-C → 150Ω の抵抗 → 電源の －（GND）と、ひと回りして流れる
  • GP40T はラズパイの上に載せる基板。ラズパイとは電気的に分けた（絶縁した）電源で動く（GPIO27 で電源を入れる）

数字の計算

電圧[V] = GP40T の数字 × 1.25mV 電流[mA] = 電圧[V] ÷ 150Ω × 1000 温度[℃] = -19.9 + (電流 − 4) ÷ 16 × 79.9 （4mA = -19.9℃、20mA = 60.0℃） 湿度[%] = (電流 − 4) ÷ 16 × 99.9 （4mA = 0%、20mA = 99.9%）
  • 例：温度側が 1.32V → 8.8mA → -19.9 + 4.8 ÷ 16 × 79.9 = 4.1℃
  • 3.6〜20.5mA を外れたら、断線・故障の疑いとして記録しない
  • GP40T は 0〜5V のレンジで使う（実際は 0〜5.12V まで測れる）
